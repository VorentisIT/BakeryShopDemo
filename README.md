# Délice Bakery & Pâtisserie

A luxury artisan French bakery and pâtisserie web application crafted with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- **Artisanal Cakes, Desserts & Viennoiserie Catalogs**
- **Atelier Services**: Bespoke Wedding Cakes, Event Pastry Catering, Corporate Luxury Gifting, Baking Masterclasses, and Chef's Tasting Table
- **Interactive Visual Lookbook & Lightbox Modals**
- **Custom 3D Cake Studio Builder**
- **Full Slide-Over Cart Drawer & Multi-Step Luxury Checkout**
- **Chef's Craft Documentary Video Showcase**
- **Responsive Mobile Navigation Drawer with Accordion Support**
